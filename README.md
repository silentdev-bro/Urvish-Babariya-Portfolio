# Urvish Babariya — Developer Portfolio

This is a modern, production-ready developer portfolio built with Next.js, Tailwind CSS, Framer Motion, and Three.js.

## Getting Started

1. **Install Dependencies:**
   \`\`\`bash
   npm install
   \`\`\`

2. **Run the Development Server:**
   \`\`\`bash
   npm run dev
   \`\`\`
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Adding your real photo and Resume

- **Photo**: Drop your real square profile photo (recommended $\ge$ 800x800px) as `profile.jpg` in the `/public` folder. If the file is missing, the site gracefully degrades to a stylized initial avatar.
- **Resume**: Drop your actual PDF resume as `resume.pdf` in the `/public` folder. The "Résumé" button in the navigation bar automatically links to this file.

## Deployment

This portfolio is ready to be deployed on [Vercel](https://vercel.com/new).
Simply push the repository to GitHub, connect it to Vercel, and click deploy. The default Next.js build settings will work out of the box.
